Eine **Tour** fasst mehrere Routen zu einer Reise zusammen - zum Beispiel die Tagesetappen einer Wochenfahrt. Eine Tour hat einen Namen, eine Beschreibung, Schlagwörter (Tags), Fotos und die **geordnete Liste ihrer Routen**; ihre Gesamtlänge rechnet YTAN selbst aus.

## Das Touren-Fenster öffnen

Menü > **Touren**. Oben suchst du nach Name, Beschreibung oder Ersteller und kannst die Länge (von - bis) eingrenzen. Darunter stehen **Meine Touren** und **Öffentliche Touren**.

![Die Tourenliste](touren.jpg)

Jeder Eintrag zeigt Name, Länge, Zahl der Routen und - bei veröffentlichten Touren - die Markierung **Öffentlich**. Tippe einen Eintrag an, um die Details zu sehen.

## Die Tour-Details

![Details einer Tour](tour-details.jpg)

Die Detailseite zeigt Beschreibung, Tags, Fotos und die Routen der Tour in ihrer Reihenfolge. Darunter stehen die Aktionen:

| Schaltfläche | Wirkung |
|---|---|
| **Tour-Modus aktivieren** | Zeigt auf der Karte nur die Routen dieser Tour (siehe unten). |
| **Routen bearbeiten** | Routen hinzufügen, entfernen und in der Reihenfolge verschieben. |
| **Bearbeiten** | Name, Beschreibung, Tags und Fotos ändern. |
| **Veröffentlichen** / **Veröffentlichung aufheben** | Macht die Tour für alle sichtbar - oder wieder privat. |
| **Kopieren** | Legt eine eigene Kopie der Tour an. |
| **PDF herunterladen** | Erzeugt ein Tourenblatt mit Karte, Beschreibung, Fotos, Routen und POIs entlang der Strecke. |
| **GPX exportieren** | Lädt alle Routen der Tour als eine GPX-Datei (je Route ein Track). |
| **Teilen** | Erzeugt einen Link auf die Tour (nur bei öffentlichen Touren). |
| **Löschen** | Löscht die Tour. Ihre Routen bleiben erhalten. |

Welche Schaltflächen du siehst, hängt von deinen Rechten ab (siehe unten).

## Eine Tour anlegen

1. Tippe im Touren-Fenster oben rechts auf **+ Neue Tour**.
2. Gib einen **Namen** (mindestens drei Zeichen) und eine **Beschreibung** ein. Füge **Tags** hinzu: Schlagwörter wie „Ostsee" oder „Mehrtagestour", die beim Suchen helfen.
3. Speichere. Fotos kannst du hinzufügen, sobald die Tour existiert (Bearbeiten).
4. Tippe auf **Routen bearbeiten** und wähle aus der Liste deiner eigenen Routen aus, welche zur Tour gehören. Mit den Pfeilen sortierst du sie in die Reihenfolge der Etappen.

Schneller geht es von der Karte aus: Im Kontextmenü einer Route (oder über das Symbol links unten im Infofenster) wählst du **Zur Tour hinzufügen**, suchst die Tour und tippst sie an. Dort gibt es auch **+ Neue Tour…**

> **Hinweis:** Eine Tour kann nur **deine eigenen** Routen sowie **öffentliche** Routen enthalten.

## Tour-Modus

Der Tour-Modus blendet alle Routen aus, die nicht zur Tour gehören. So siehst du die geplante Reise ohne Ablenkung - und die Etappen mit ihren Entfernungen.

![Der Tour-Modus](tour-modus.jpg)

Oben links zeigt ein Hinweis den Namen der Tour. Das **×** daneben beendet den Modus.

## Wer darf was?

Touren haben eigene Rechte, die Administratoren vergeben:

| Recht | Erlaubt |
|---|---|
| **Touren anlegen** | Eigene Touren anlegen, bearbeiten und löschen. |
| **Touren veröffentlichen** | Eigene Touren für alle sichtbar machen. |
| **Touren kopieren** | Touren (auch fremde öffentliche) kopieren. |
| **Touren verwalten** | Alle Touren bearbeiten, auch fremde. |

Fehlt ein Recht, fehlt die zugehörige Schaltfläche. Eine **private** Tour sehen nur du und die Verwalter.

## Wenn eine Route einer Tour geändert wird

Ändert oder löscht jemand eine Route, die in Touren steckt, passiert Folgendes:

- Die **Gesamtlänge** der betroffenen Touren wird neu berechnet.
- Die **Ersteller** der betroffenen Touren bekommen eine **E-Mail** darüber.
- **Löschen** muss bei einer Route in einer Tour durch eine kleine **Rechenaufgabe** bestätigt werden, damit es nicht versehentlich passiert.
